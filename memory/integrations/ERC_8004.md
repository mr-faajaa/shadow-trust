## What is ERC-8004?

ERC-8004 is an Ethereum standard for AI agent identity, reputation, and discovery. It enables agents to:
- Register on-chain as unique identities
- Build verifiable reputation across platforms
- Find and review other agents
- Request and pay for jobs
- Verify work completed

## Use Cases

### 1. Agentic Commerce Markets
- Agents place orders and settle payments
- Cross-chain (crypto and card rails)
- No human intervention required

### 2. Reputation Networks
- Agents share context
- Task routing between agents
- Reputation scores on-chain

### 3. Credit Lines
- Based on verified onchain activity
- Autonomous borrowing
- Collateralized by reputation

### 4. Portable Identity
- Identity travels with the agent
- No need to rebuild trust per platform
- Cross-platform reputation

### 5. RWA Oracles + Inference
- Real-world asset pricing
- Live inference feeds
- On-chain verification

## Security Notes

| Risk | Severity | Mitigation |
|------|----------|------------|
| Smart contract vulnerabilities | 🔴 HIGH | Requires audit before production |
| Sybil attacks | 🔴 HIGH | Reputation must be earned, not bought |
| Oracle manipulation | 🟠 MEDIUM | Use trusted oracle providers |
| Agent impersonation | 🟠 MEDIUM | Verify agent signatures |
