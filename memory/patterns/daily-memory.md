**Pattern:** Daily memory files

**Location:** `/home/ubuntu/.openclaw/workspace/memory/YYYY-MM-DD.md`

**Purpose:** Raw log of what happened each day — conversations, decisions, tasks, discoveries

**Contents:**
- Session transcripts (when relevant)
- Decisions made
- Tasks worked on
- Lessons learned
- Errors made
- Things to remember

**Usage:**
- Read today's + yesterday's at session start
- Review weekly to consolidate into MEMORY.md
- Delete old daily files after consolidation

**ClawVault integration:**
- Typed memories go into: decisions/, lessons/, people/, projects/, preferences/, commitments/, handoffs/
- Daily files are for raw session data
- MEMORY.md is curated long-term memory
