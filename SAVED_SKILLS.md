## Installation Commands
```bash
# UI Skills
npx ui-skills add baseline-ui
npx ui-skills add frontend-design
npx ui-skills add tailwind-css-patterns

# Remotion (when working)
npx remotion create

# Other useful skills
npx skills add github:BankrBot/openclaw-skills
```
